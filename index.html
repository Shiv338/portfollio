About Me

Hello! I'm a developer who loves turning ideas into clean, working software. My journey started with simple HTML pages, and it quickly grew into a passion for building complete, useful applications. I enjoy the moment when an idea on a whiteboard becomes a product that real people can use and benefit from.

Over the past few years I've worked across the stack — crafting user interfaces with HTML, CSS and JavaScript, writing clean back-end logic in Python (this site stores messages to MongoDB via a Flask API), and learning strong software design patterns in Java. I care about writing code that is readable, tested, and easy to maintain, not just code that works today.

When I'm not coding, you'll find me exploring new developer tools, contributing to small open-source projects, and reading about the latest in web performance and accessibility. I'm always happy to collaborate — feel free to reach out through the contact section below.
